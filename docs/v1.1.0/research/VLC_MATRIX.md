# VLC 3.x feature matrix vs Kodi 21 (Omega) VideoPlayer

Scope: Kodi 21 internal VideoPlayer on Windows and Android TV. Player UI = skin OSD (VideoOSD.xml, custom dialogs) + Python service/plugin. External VLC is out of scope.

Legend:
- **Kodi native**: exact action (keymap `Action(...)` / `xbmc.executebuiltin`), builtin, JSON-RPC v13 method, setting id or InfoLabel.
- **unverified**: name taken from memory of Kodi source/wiki but not re-checked against Kodi 21 docs while writing this file. Check before coding.
- Priority: P0 = must ship in v1.1.0, P1 = should, P2 = nice to have.

## Implementation notes

- `SubtitleDelayPlus/Minus` step is 0.1 s; audio delay step is smaller (0.025 s, unverified). There is no absolute delay setter in JSON-RPC, so coarse steps and bookmark-sync must loop the step actions and read back `Player.SubtitleDelay`/`Player.AudioDelay` (strings like "-0.300 s", parse the float).
- Audio/subtitle delay, view mode, zoom, deinterlace and chosen streams are persisted per file in the `settings` table of `MyVideos*.db` (columns `AudioDelay`, `SubtitleDelay`, `ViewMode`, `ZoomAmount`, `PixelRatio`, `Deinterlace`/`InterlaceMethod`, `AudioStream`, `SubtitleStream`). Defaults for new files come from the "Set as default for all media" button. Do not write the DB directly.
- Sign convention: VLC `spu-delay` positive = subtitles later. Confirm Kodi's direction empirically before shipping the bookmark sync formula.
- Tempo (`PlayerControl(Tempo(x))`) is limited to ~0.8-1.5x and can be unavailable with passthrough audio; passthrough (AC3/DTS to AVR) disables tempo and volume amplification.
- `xbmc.Player().setSubtitles()` adds an external stream; calling it repeatedly (dual subs regeneration, encoding fix) accumulates streams. Reuse a fixed temp filename and select it via `Player.SetSubtitle`.
- Kodi's subtitle renderer is libass for ASS/SSA and converts SRT to ASS internally, so `{\an8}` in SRT is honored (verify on Android).
- Hebrew: prefer UTF-8 conversion in Python over changing `subtitles.charset` globally; RTL punctuation issues are a font/renderer matter (use Arial or a Hebrew-capable font via `subtitles.font`, unverified id).
- Global setting changes via `Settings.SetSettingValue` persist in guisettings.xml; restore user values if used as temporary overrides.
- Android TV remotes have few keys: bind features to OSD buttons and long-press (`longpress` keymap section) rather than keyboard hotkeys.
- Verification status: Kodi facts in this file were compiled from knowledge of Kodi source/wiki; items marked "unverified" were not checked against Kodi 21 docs (kodi.wiki Action_IDs, List_of_built-in_functions, InfoLabels, JSON-RPC v13) during writing.
