# BN player keys (v1.1.0)

Remote first: every function is reachable with D-pad + OK + Back through the OSD bar (OK on the video opens it).
Keyboard shortcuts mirror VLC where Kodi does not already use the key (`resources/keymaps/bn_player.xml`,
installed to `userdata/keymaps/bn_player.xml` by the NovaTV service).

| Key | Action | VLC equivalent |
|---|---|---|
| G / H | subtitle delay −0.1 s / +0.1 s | G / H |
| J / K | audio delay −0.025 s / +0.025 s | J / K |
| Shift+S | Sync panel (coarse steps, bookmark sync, reset) | Shift+H/J/K |
| V | Subtitles menu (generate, picker, appearance) | V (cycle subtitles) |
| T | next subtitle track | V |
| B | next audio track | B |
| [ / ] | playback speed −/+ (when Kodi allows tempo for the file) | [ / ] |
| Ctrl+E | player settings (gear) | Ctrl+E (effects) |
| N | next episode | N |
| A | aspect ratio | A |
| Shift+P | screenshot | Shift+S |
| Remote "Subtitle" key | Subtitles menu | – |
| Remote "Language/Audio" key | next audio track | – |

Kodi defaults stay: Space pause, arrows seek, I info, O codec info, M OSD, Esc/Back close.
