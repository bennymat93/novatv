Kodi 20.5 לאייפון ואייפד (IPA)

נבנה מהקובץ הרשמי של Kodi (mirrors.kodi.tv), בלי שום שינוי בתוכן. 150 מ"ב. נדרש iOS 11 ומעלה.

התקנה

  1. מעבירים את הקובץ למחשב (או מורידים אותו ישירות במחשב מהדף הזה).
  2. מתקינים Sideloadly (sideloadly.io), מחברים את האייפון בכבל, גוררים את הקובץ, מזינים Apple ID ולוחצים Start.
  3. באייפון: הגדרות ← כללי ← ניהול VPN ומכשירים ← ה-Apple ID ← אמון.
  4. עם Apple ID חינמי חותמים מחדש כל 7 ימים.

הקובץ שמור באתר בשני חלקים (לאתר יש מגבלה של 100 מ"ב לקובץ). הדף מוריד את שניהם, מחבר אותם, בודק את טביעת האצבע (SHA-256) ושומר קובץ אחד שלם.
